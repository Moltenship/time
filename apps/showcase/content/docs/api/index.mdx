Import from `@moltenship/calendar`. It includes the React components and hooks, the event engine,
the Temporal helpers, and the pointer interactions, so one import line covers everything:

```ts
import { createCalendar, defineCalendarView, plainDateInterval } from "@moltenship/calendar";
```

## Packages

| Package                         | Contents                                                         | Dependencies                                          |
| ------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------- |
| `@moltenship/calendar`          | Re-exports the four packages below                               | Those four; React 19 (peer)                           |
| `@moltenship/calendar-react`    | `createCalendar`, `defineCalendarView`, components, hooks, store | `calendar-core`, `calendar-temporal`; React 19 (peer) |
| `@moltenship/calendar-core`     | Adapters, validation, snapshots, queries. No React.              | `calendar-temporal`, `@flatten-js/interval-tree`      |
| `@moltenship/calendar-temporal` | Ranges, grids, rounding, zoned days, DST                         | None                                                  |
| `@moltenship/calendar-dnd`      | Pointer drag, resize, and create for views                       | `calendar-core`, `calendar-temporal`; React 19 (peer) |

Every package is ESM only. Import from the package name: paths inside a package aren't part of the
API.
