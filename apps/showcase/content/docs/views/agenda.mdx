Try it in the [live demo](https://moltenship-time-demo.vercel.app): pick Agenda in the view switcher.

`createAgendaView` lists the events in the coming weeks, one group per day. Days without events are
left out.

## Add it

Copy `registry/list-view` into your app, along with the theme and `registry/calendar`, as described
in [UI source](/docs/installation#ui-source-optional). Then register the view:

```tsx
import { createAgendaView } from "@/components/calendar/list-view/agenda-view";

export const Calendar = createCalendar<Meeting>()({
  eventAdapter,
  views: [createAgendaView<Meeting>({ weeks: 2, getEventColor: (meeting) => meeting.color })],
});
```

The view is named `agenda`.

## What it shows

- **Days:** each day with events gets a date column that stays in view while you scroll its
  events. Today is highlighted.
- **Times** are formatted as a range with `Intl`, as in "10:00 – 11:30 AM". Events that started the
  day before read "Until 2:00 AM"; events that run into the next day read "From 10:00 PM".
- **All-day events** show an "All day" badge, and events longer than a day show "Day 2 of 3".
- **Empty range:** a short message when the weeks shown have no events.
- **Clicking a date** opens that day in the view named `day`. Register a
  [day view](/docs/views/week-and-day) so the click has somewhere to go.
- **Changes being saved:** events with a [pending change](/docs/interactions#pending-changes) get
  `aria-busy` and render at 60% opacity.

Each day has `data-date`, and each event is a `<button>` with `data-event-id`.
