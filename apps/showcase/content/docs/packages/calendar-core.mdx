---
title: "@moltenship/calendar-core"
description: Framework-independent event validation, immutable snapshots, and indexed interval queries.
---

The core package accepts application records through an `EventAdapter`, validates and normalizes
them once per immutable array snapshot, and exposes read-only interval and resource queries.

Key exports include `defineEventAdapter`, `createEventSnapshot`, `createEventSnapshotCache`,
`validateCalendarEvent`, event and resource ID guards, canonical event contracts, environments, view
strategies, and transaction types.

Applications using React normally receive these exports from `@moltenship/calendar`. Import the core
package directly for framework-independent engine work.

See [event and snapshot APIs](/docs/api/events).
