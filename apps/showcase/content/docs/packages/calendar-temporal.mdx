---
title: "@moltenship/calendar-temporal"
description: Native Temporal interval constructors, predicates, comparison, and arithmetic.
---

This framework-independent package provides type-specific helpers for `Temporal.Instant`,
`Temporal.PlainDate`, and `Temporal.PlainDateTime` intervals. It preserves half-open semantics and
never converts boundaries through legacy `Date` or numeric milliseconds.

Use it when authoring pure engine strategies or framework-independent calendar algorithms. React
application code can often remain on the supported facade while a view package owns Temporal range
construction.

The package does not polyfill or re-export the platform `Temporal` namespace. Runtimes must provide
the ambient global before application code executes.
