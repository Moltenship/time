title: "@moltenship/calendar-react"
description: React 19 state bindings, typed factories, compound primitives, and custom-view registration.
---

The React package owns the state bridge and one factory-private context for each calendar. Its
compound surface includes `Root`, `Frame`, `Toolbar`, navigation triggers, `Title`, `Viewport`,
`ActiveView`, `CustomView`, `ViewSwitcher`, and indexed `Event` rendering.

The public hooks expose semantic state, actions, metadata, and selectors. Jotai is an internal
runtime detail and no atom or dependency-owned store type crosses the package boundary.

Use `defineCalendarView` for reusable registrations or `Calendar.defineView()` for a factory-local
view that knows the complete view-name union.

See [React composition APIs](/docs/api/react).
