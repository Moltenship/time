You'll build this calendar in React: a toolbar, a view switcher, and the built-in week, day, month
and agenda views, showing your own meetings.

<CalendarPreview switcher />

To see these views running with more data before you start, open the [live demo](https://moltenship-time-demo.vercel.app).

<Steps>
<Step>

### Install

Install `@moltenship/calendar` and its peer dependencies as [Installation](/docs/installation#install)
describes, with a `Temporal` polyfill if your browsers need one.

</Step>
<Step>

### Add the UI source

The views are source files that you add to your app with the shadcn CLI. They use shadcn/ui's
tokens and bring their own controls, so any shadcn style works (see
[UI source](/docs/installation#ui-source-optional)). Name ui-sdk's CSS layer before Tailwind in
your global CSS, then add the week and day, month, and agenda views:

```css title="globals.css"
@layer ui-sdk;
@import "tailwindcss";
```

```bash
npx shadcn@latest add \
  https://time.molten.sh/r/time-grid-view.json \
  https://time.molten.sh/r/month-view.json \
  https://time.molten.sh/r/list-view.json
```

They bring the theme, the toolbar, view switcher and event chip from the shared `calendar` item,
and the calendar's controls and popups from `calendar-ui`. The files land in
`components/calendar/` and are yours to change, as [Customization](/docs/customization) describes.
The controls are built on ui-sdk, so name its CSS layer before Tailwind in
your global CSS:

```css title="globals.css"
@layer ui-sdk;
@import "tailwindcss";
```

</Step>
<Step>

### Create the calendar

Describe your records with an adapter, then create a calendar with the views you want. The first
view in the list is shown first.

<include meta='title="calendar.tsx"'>../examples/quick-start.tsx#calendar</include>

`getEventColor` picks each event's color from the [palette](/docs/theming#event-colors).
`dayView: "day"` makes the dates in the week header open the day view.

</Step>
<Step>

### Render it

`Root` holds the calendar state. It needs your events, a starting date, a time zone, a locale, and
week rules (the first day of the week, where 1 is Monday, and the weekend days).
`CalendarToolbar` adds the Today, previous, and next buttons and the title, and the registry's
`ViewSwitcher` switches between your views.

<include meta='title="calendar.tsx"'>../examples/quick-start.tsx#root</include>

Give the frame a height: the views fill it and scroll inside it. The calendar is read-only until
you add an `onEventChange` handler; [Interactions](/docs/interactions) shows how to save dragged and
resized events.

</Step>
</Steps>

<Callout title="Using Next.js?">
  Calendar modules are Client Components, which is why the file starts with `"use client"`. See
  [Next.js and server rendering](/docs/guides/nextjs) for passing data from a Server Component.
</Callout>
