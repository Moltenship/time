# Deterministic benchmark fixtures

`fixtures` is an internal workspace package. It owns reproducible semantic input data; it does not
own calendar algorithms or publish performance claims.

The default fixture generated by `generateBenchmarkFixtures()` contains:

- 10,000 application-native events using the public core event contracts;
- 500 canonical resources;
- 1,000 visible fragments with stable keys;
- intervals distributed over 365 days with deterministic overlaps and multi-day all-day spans;
- gap, fold, half-hour fold, midnight transition, and unusual-offset DST cases.

The generator is deterministic across machines because it uses integer PRNG operations and formats
its ISO values directly. It does not read the current clock, host timezone, locale, or global
Temporal implementation. A caller can request smaller counts for unit tests without changing the
default benchmark profile.

Consumers import only the package entry point:

```ts
import { generateBenchmarkFixtures } from "fixtures";
```
